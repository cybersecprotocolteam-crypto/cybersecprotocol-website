Learn cybersecurity from zero

A plain roadmap for complete beginners: what to learn first, in what order, and how to practise without breaking the law. It is free to read, and everything here is also taught, step by step, in the Cybersec Protocol app.

1. Start with the three goals

Every security idea comes back to three words: confidentiality (only the right people can see the data), integrity (the data is not changed without permission) and availability (the system works when you need it). Every attack breaks at least one of them, and every defence protects at least one. If you remember only this, you can already reason about most incidents.

2. Learn how the internet really works

IP addresses, DNS, HTTP and HTTPS, TCP and UDP, ports, firewalls and VPNs. You do not need to memorise protocols; you need to be able to picture what happens when you open a web page, because attacks happen at each of those steps.

3. Get comfortable in a Linux terminal

Most servers run Linux, and many security tools were built for it. Learn to move around (pwd, ls, cd), read files (cat, head, tail), search (grep), chain commands with pipes, and read file permissions. Counting failed logins in a log with one line is a very good first win.

4. Pick one programming language

Python is the usual first choice for automation and tools. C shows what the computer does with memory, which explains attacks such as buffer overflows. JavaScript and SQL are what you need to understand web attacks: cross-site scripting and SQL injection only make sense once you have seen the code that allows them.

5. Learn how attacks work, so you can defend

Phishing and other social engineering, weak and reused passwords, malware, and the most common web weaknesses. The point is to recognise the pattern, not to memorise tools. Tools change every year; the patterns do not.

6. Practise only where it is legal

Learning is legal. Testing a system you do not own, without written permission, is not, even out of curiosity. Practise on your own devices and on labs built for learning, such as TryHackMe, OverTheWire and the PortSwigger Web Security Academy.

7. Keep notes and build small projects

A log parser, a password strength checker, a scan of your own home network. Notes and small projects are what you will show later, and they make the knowledge stay.

8. Choose a direction

Security has many areas: defence and monitoring, ethical hacking, privacy, cloud security, and more. Read a few full lessons for free in the lesson library, or see the basics roadmap for what to learn first.

Questions beginners ask

How long does it take?

There is no fixed time. Twenty minutes a day for a few months is enough to get through the basics.

Do I need to know how to code?

Not at the start. You will need a little later, and the earlier you begin, the easier it is.

Is it legal to learn hacking?

Yes, as long as you only test your own systems or systems you have written permission to test. The lessons use safe simulations for exactly this reason.
