Install the APK safely

  1. Download the APK from this page only (cybersecprotocol.app). Never from a copy sent in a chat or posted elsewhere.
  2. Check its fingerprint (below). If it is different, delete the file: it is not ours.
  3. Open it. Android asks to allow your browser or file app to install apps: allow it for this once.
  4. After installing, go back to Settings > Apps > Special access > Install unknown apps and switch that permission off again.

Updates: the app checks this website for a newer version and installs it only if the file has the right fingerprint, the same package name and the same signing key. Android always asks you before installing.
