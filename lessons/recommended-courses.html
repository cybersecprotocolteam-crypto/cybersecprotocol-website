Recommended Courses

Intro to Cybersecurity · about 5 minutes

1. Courses to start with

These well-known courses are a great next step after this app. Tap a card to open it in your browser.

CS50's Introduction to Cybersecurity (Harvard): A free, beginner-friendly course on securing accounts, data, systems and software. No programming needed.

Introduction to Cybersecurity (Cisco Networking Academy): A free, self-paced course on threats, attacks and how to protect yourself, with a certificate of completion.

Google Cybersecurity Certificate: A longer program on Coursera covering security operations, Linux, SQL and Python, for people who want to go further. Paid, with financial aid available.

2. Practice platforms

TryHackMe: Guided labs that run in your browser. The Pre Security path is a gentle start.

OverTheWire: Bandit: A free game that teaches the Linux command line, level by level.

PortSwigger Web Security Academy: Free web security lessons and labs from the makers of Burp Suite.

3. When you want a certificate

If you later want a certificate, common first steps are CompTIA Security+ and ISC2 Certified in Cybersecurity (CC).

Professor Messer: Free video courses for the CompTIA A+, Network+ and Security+ exams.
